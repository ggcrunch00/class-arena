# 학급 로그인 붙이기 계획 (11-06 선생님과 정함)

## 모드별 로그인
| 모드 | 로그인 | 까닭 |
|---|---|---|
| 연습 대전 | 없음 | 집·쉬는 시간 연습, 주제는 학생이 고름 |
| 둘이서 대전 | 없음 | 기기 하나로 나란히 |
| 오늘의 도전 | 없음 | 모두 같은 문제 |
| 원정 | 필요(붙일 때부터) | 선생님이 정한 출제 범위, 기기를 바꿔도 이어 하기, 학급 기록 |
| 협동 작전·PvP | 필요 | 방 만들기·같은 반 매칭에 서버 필요 |

- 영웅·기사단 막사·훈련소는 원정 전용. 대전 모드는 모두 같은 조건(훈련 효과 없음).
- 로그인을 붙이기 전까지 원정 주제는 학생이 여러 개 고름(빈틈은 붙일 때 선생님 범위로 닫음).

## 어디에 붙이나
`game/src/play/account.js` 한 파일만 바꿈.
- `who()` 로그인한 학생(학급 이름·번호).
- `loadCamp/saveCamp` 원정 진행(별·도전 별·진 횟수·영웅·훈련·본 머리말)을 서버에 저장, 기기 사본은 그대로(인터넷이 끊겨도 계속).
- `campRange(picked)` 선생님이 학급에 정한 출제 범위를 돌려줌. `canPickCampTopics()`가 false면 원정 지도의 주제 단추가 잠김.
- `report(summary)` 판 끝 요약 `{stage, won, stars, hard, right, wrong, topics, time}` → 학급 기록 표.

## 통합 학급 로그인 저장소에 바라는 것
「이름을 쓰는 섬」의 class-login(학급 코드 5글자 + 번호 + 그림 비밀번호, 교사 Google 로그인, 학생 이름 수집 안 함)을 통합 저장소로 옮길 때:
1. 게임별 학급 설정 칸(지금 `cl_packs`, app = `class-arena`)에 아라 원정대 출제 범위를 담을 수 있게.
   - 예: `{ topics: ["gugu", "saja"], format: "mix", lockTopics: true, modes: ["camp"], ai: "knight" }`
2. 관리 사이트의 게임 목록에 아라 원정대 추가, 게임별 설정 화면(주제 여러 개 고르기)을 끼울 자리.
3. 게임별 저장(`cl_saves`, part: `camp`, `summary`)과 기록 표(요약 `summary`).
4. 모듈을 한 주소에서 불러올 수 있게(예: 통합 저장소 Pages의 `classlogin.js`), 판 올림 표시.
5. 서버가 없거나 끊기면 "이 기기에 저장"으로 계속(지금 모듈과 같음).
