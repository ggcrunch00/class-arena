# 사회 빈칸 문제 은행 쓰기 — 공통 안내

교실 대전 게임 「아라 원정대」(초등 5·6학년)의 사회 문제 은행 JSON을 단원별로 새로 쓴다.
학생은 문장 속 빈칸(＿)에 알맞은 말을 글자 타일로 만들거나, 객관식(정답 r + 헷갈리는 말 x)·OX로 푼다.

## 자료
- 단원 개념 목록: 글감 시트(드라이브)에서 단원 개념 줄만 뽑은 목록
  (핵심어 | 소주제 | 설명 | 헷갈리는 말). 출판사 단원 정리에서 모은 것이라 **문장을 그대로 옮기면 안 된다.** 개념과 사실만 뽑아 문장은 새로 쓴다.
- 형식 본보기(이미 있는 은행): `game/src/play/bank/civic6.json`, `hist6.json`. 먼저 읽어 볼 것.

## 파일 형식 (`game/src/play/bank/<단원키>.json`)
```json
{
  "name": "짧은 주제 이름(8글자 안팎)",
  "hint": "5학년 · 핵심 소주제 두세 개",
  "kind": "교과형",
  "grades": [5, 5],
  "units": ["5-1 단원 이름(소주제들)"],
  "note": "r 바른 말, x 헷갈리는 말, s 문장(＿ 뒤에 받침 따라 바뀌는 조사가 오지 않게 씀), why 까닭(해요체), g 학년, d 난이도. 단원 개념만 참고하고 문장은 새로 씀.",
  "items": [
    { "r": "선거", "x": ["재판", "공약"], "s": "시민을 대신할 대표를 뽑는 일은 ＿ 쪽이에요.", "why": "선거로 시민의 대표를 뽑아요.", "g": 5, "d": 0 }
  ]
}
```
항목은 한 줄에 하나씩(본보기 파일처럼) 쓴다.

## 규칙(검사기가 확인함)
1. **문항 수 40개 이상, 난이도 d0·d1·d2가 각각 13개 이상.** d0 = 단원의 가장 기본 낱말, d1 = 중간, d2 = 자세한 사실·어려운 낱말.
2. s에 빈칸 `＿`(전각 밑줄 U+FF3F)은 정확히 1개. 빈칸을 r로 채운 문장은 해요체(…요.)로 끝난다.
3. **빈칸 바로 뒤에 받침에 따라 모양이 바뀌는 조사(은/는/이/가/을/를/과/와/으로/로/이에요/예요/이며 …)를 두지 않는다.** 정답과 오답 중 무엇을 넣어도 자연스러워야 하기 때문.
   좋은 꼴: "…은 ＿ 쪽이에요.", "＿ 제도가 있어요.", "＿ 시대에 …", "＿ 덕분에 …", "＿ 지역에서 …", "＿ 의 …"(의·에·에서·도·만·까지·처럼·보다는 괜찮음).
4. 빈칸을 채운 문장 길이(＿ 포함)는 46글자 이하. 짧고 분명하게.
5. x는 1~3개. 같은 갈래(사람이면 사람, 제도면 제도, 지역이면 지역)이면서 **그 문장에서는 분명히 틀린 말**. 정답과 같은 뜻·띄어쓰기만 다른 말 금지. 보기 낱말은 되도록 6글자 이하.
6. why는 해요체 한 문장(…요.)으로, 왜 그 답인지 알려 준다(정답 낱말을 넣어도 됨).
7. g는 학년(그 단원 학년), d는 0~2.
8. 사실은 초등 교과서 수준에서 **확실한 것만**. 연도·인물·지명이 조금이라도 불확실하면 그 문항은 쓰지 않는다. 그림을 봐야 풀 수 있는 것, 지역·시기마다 답이 갈리는 것은 쓰지 않는다.
9. 말투·내용: 초등학생이 읽는 글. 어려운 한자어는 풀어 쓰고, 잔인하거나 자극적인 묘사(학살·고문 장면 등)는 쓰지 않는다. 역사는 사실 위주로 중립적으로. 실제 개인(일반인)의 사례·이름은 쓰지 않는다(역사 인물은 괜찮음).
10. 다른 은행과 겹치지 않게: 이미 있는 주제(우리나라 기후·인구, 세계 지리, 6·25·민주화·산업화, 선거·국가 기관)와 같은 문장을 다시 쓰지 않는다.

## 하지 말 것
- 저장소의 다른 파일(코드·다른 은행)은 고치지 않는다. git 커밋·푸시도 하지 않는다.
- 웹에서 문장을 가져오지 않는다.
